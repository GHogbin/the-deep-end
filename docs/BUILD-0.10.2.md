# The Deep End 0.10.2-26.3 testing

This build corrects the custom renderer's vertical coordinate transform so the platform, towers, frame, crystals, and pylons share one coherent origin. The display entity is also invulnerable to prevent damage tinting.

Install only this jar, place a shrine with `/deepend shrine`, and right-click it with a Resonant Crystal. The expected result is one cohesive custom shrine model with dark stone, cyan runes, and violet crystal parts.
