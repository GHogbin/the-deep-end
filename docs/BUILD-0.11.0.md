# The Deep End 0.11.0-26.3 testing

This build begins the datapack-driven shrine phase. A dormant Observation Shrine anchor can be activated with a combination of Resonant Crystal, Chorus Fibre, and Resonance Lens. The active footprint is placed by datapack functions, not by the custom Java cube renderer.

## Test

1. Install only the 0.11.0 jar.
2. Run `/deepend shrine`.
3. Give yourself one each of a Resonant Crystal, Chorus Fibre, and Resonance Lens.
4. Hold the Resonant Crystal and right-click the shrine.
5. Confirm the three items are consumed and the stepped active shrine footprint appears.
6. Sneak-right-click the anchor with a Resonant Crystal.
7. Confirm the datapack footprint clears and the dormant single-block anchor returns.
8. Right-click with only the crystal and confirm activation is refused without consuming it.
