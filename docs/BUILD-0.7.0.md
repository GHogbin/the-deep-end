# 0.7.0 single-block shrine baseline

The shrine is temporarily reverted to a single Observation Shrine block. `/deepend shrine` places one block ten blocks south of the player, and natural distant discovery places one shrine block on a valid End surface. The custom renderer, multiblock recipe, collision scaffold and restoration code remain available in the source but are not used by the current placement paths.

Test with `/deepend shrine` in an empty loaded position. Confirm exactly one block appears and that the game loads without structure errors. The Resonant Crystal interaction is intentionally paused until the shrine structure phase resumes.
