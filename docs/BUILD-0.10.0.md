# The Deep End 0.10.0-26.3 testing

This build upgrades the paused custom shrine renderer to more closely match the reference image: a broad stepped platform, front staircase, asymmetrical rear towers, four corner pylons, broken angled frame, rune channels, pedestal, and suspended crystal.

The custom model is shown when a complete shrine is activated with the Resonant Crystal. The ordinary single-block shrine remains unchanged until activation.

## Test

1. Install only `the-deep-end-26.3-0.10.0-26.3.jar`.
2. Use `/deepend shrine` to place the single-block shrine.
3. Build or use the complete shrine recipe from the existing shrine test.
4. Activate the completed shrine with the Resonant Crystal.
5. Inspect the model from the front, sides, and above.
6. Confirm the model contains the stepped platform, stairs, towers, corner pylons, angled frame, glowing runes, floating crystal, and front pedestal.
7. Sneak-right-click the awakened shrine with the Crystal to restore the block build.
